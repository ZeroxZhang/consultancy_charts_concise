# 布局原型索引 · D-01…D-12

先完成[整页构思](slide_anatomy.md)，需要实现骨架时再查本表。编号保留原含义，比例和具体绘制方式由内容决定；这里不规定常用优先级、图型数量、段落数或填充率。画布与角色预算以slide_anatomy及字体配置为准。

| 原型 | 能承担的阅读任务 | 可用结构与关键取舍 |
|---|---|---|
| D-01 纯文本 | 需要精读的论证、原则或引文 | 按论证层级排版；有主体/依赖/条件时先判断是否图示更清楚，不默认把定性材料做成段落栏 |
| D-02 单图表 | 一个充分展开的核心比较 | 主图统领正文，标题、图例、标签共同布局；没有新增含义不另加takeaway |
| D-03 图表＋解释 | 数据与机制/边界需要配合 | 解释贴近对象，可侧置、嵌入或置下；主辅面积按证明责任决定，不默认2:1或等高 |
| D-04 多展品 | 互补证据或同口径分面 | 按阅读顺序安排，共享有意义的尺度/锚点；避免重复数值与独立组件各自居中 |
| D-05 表格 | 精确查值、共同维度比较 | 同行轨道、单位和列头清楚；微型图帮助扫描，行高由内容决定 |
| D-06 框架／概念 | 层级、驱动、约束、反馈或权衡 | 关系决定形状与连接；必要证据/反例靠近关系，不为套框架强凑节点 |
| D-07 流程 | 主体之间的动作、交付与分支 | 可用泳道、连接或路径，明确方向/条件；不默认等宽chevron，顺序不冒充因果 |
| D-08 时间线／路线图 | 阶段、责任、依赖和里程碑 | 有真实日期才按时间映射；定性阶段明确非等时，路径/责任保持可读 |
| D-09 对比 | 共同维度下的方案取舍 | 矩阵、双路径或分面对照；相同维度对应，避免两边各写不同问题 |
| D-10 执行摘要 | 综合已成立的关键发现 | 可用系统图、证据结构或短论证；让关系与主次可见，不强制列表或三栏 |
| D-11 章节分隔 | 过渡、导航、主题预告 | 允许有意低密度和留白，不套正文密度要求 |
| D-12 附录 | 补充核对、方法、明细 | 按内容使用上述结构，保留与正文的对应和原尺寸可读性 |

已有CSS的evidence-ledger、benchmark-gap、driver-proof、small-multiples、evidence-table、decision-table、mechanism-chain、roadmap-lanes、scored-matrix、paired-cases仍可复用，见assets/consulting-layouts.css。名称表示一种可选结构，不是固定配方；相邻页面可以有完全不同的构思。引擎与旧样例仅供实现参考，不能自动作为当前审美质量基准。
