# 参考 09 · 端到端 worked example（从数据到成品页）

> 来源：附录 H。业务情境与数据完全虚构（页面必须标注 Illustrative）；
> 流程与规范引用为真实规则编号。拿不准流程时对照本例逐段执行。

## 1. 情境与原始数据（示意）

消费品公司"北辰食品"收入连续 3 年下滑，CEO 要求向董事会汇报诊断与建议：

| 年份 | 收入（亿元） | 线下商超 | 电商 | 经销 | 售价指数 | 销量指数 | 行业大盘增速 |
|---|---|---|---|---|---|---|---|
| 2023 | 12.0 | 7.2 | 1.2 | 3.6 | 100 | 100 | +1% |
| 2024 | 11.2 | 6.4 | 1.6 | 3.2 | 101 | 92 | −2% |
| 2025 | 10.4 | 5.3 | 2.0 | 3.1 | 101 | 85 | −5% |

## 2. So what 提炼（三步链条：数据→分析→洞察→图表信息）

收入 3 年累计 −13%；商超收入由7.2降至5.3（−26%）；提供的销量指数为公司总量，不能当作商超销量，电商 +67% 但基数小，
售价稳定仅弱化价格变动的解释；缺少产品份额和客户证据，不能排除产品力问题。
**洞察：收入下滑由线下渠道流失驱动——电商增量（+0.4 亿）只弥补了商超失血（−1.1 亿）的四成、
总缺口（−0.8 亿）的一半；行业微降说明非纯周期问题，是渠道结构问题。**
（两个"几成"分母不同：0.4/1.1 ≈ 36% 对商超失血，0.4/0.8 = 50% 对总缺口——口径必须写明，[E-09]。）
根据证据关系决定分合页；新版实物 `assets/reference_deck.html` 第7页把贡献桥与渠道规模复核组合。

## 3. Action title 与 ghost deck（每页一行标题，括号内为证明方式）

1. **收入连续三年下滑至 10.4 亿，累计缩水 13%**（折线 + CAGR [B-05]，[A-03]）
2. **商超收入下降快于公司整体，销量与行业归因仍需细分证据**（指数化折线 [B-15]，[A-03]）
3. **2025 年收入下降 0.8 亿的构成：商超 −1.1 亿，电商 +0.4 亿弥补总缺口的一半**（瀑布桥 [B-10]，[A-06]）
4. **现有售价指数稳定，产品竞争力仍需补充份额与客户证据**（价格趋势 + 证据缺口表 [B-05]，[A-03]）
5. **建议：18 个月内完成渠道重构，电商占比提至 40%，2027 年恢复正增长**（路线图 [B-52]，[A-11]）

横向逻辑检查（[E-01]）：只读五条标题 = "下滑 → 归因线下 → 拆解缺口 → 排除产品因素 → 给出建议"——成立。

## 4. 成品页完整规格拆解（选第 3 页）

**页面**：`收入下降 0.8 亿：商超拖累 1.1 亿，电商弥补 0.4 亿`（Illustrative 角标）

- **① 版式**：单图表页 [D-02]——全页一张瀑布桥，takeaway 收尾。
- **② 选图理由**：信息是"A→B 变化的贡献分解"（[A-06]）→ 桥图 [B-10]；
  起止柱 = 2024/2025 收入，中间浮动柱 = 各渠道贡献。
- **③ 数据标注**（[B-09] ③ 逐条）：
  - 起止柱：11.2 → 10.4（亿元），品牌深蓝，锚定零轴；
  - 贡献柱按业务逻辑排序：电商 +0.4（绿）、商超 −1.1（红）、经销 −0.1（红）——
    按正负贡献配色并标+/-（[E-R19]），**贡献和 +0.4−1.1−0.1 = −0.8 = 起止差**（[E-08] 复核通过）；
  - 柱间细灰连接线；起止柱顶标总额；单位写进轴标题（"亿元"）；
  - 图内不设描述性标题（页面标题即结论）。
- **④ 配色**：使用选定theme：白底；起止柱accent；贡献柱delta-positive / delta-negative，并附正负号；不把数学增减解释为经营好坏。
- **⑤ 脚注与 sticker**：`Source: 公司内部销售数据（未经审计）; Note: 口径为净收入，不含返利`；
  右上角 `Illustrative · For discussion`。
- **⑥ takeaway**：`商超的失血速度（−1.1 亿/年）决定：需要尽快检验渠道干预；时限必须另有现金流和执行依据。`

## 6. 交付前 QA（走 workflow_qa.md）——QA 是真会抓出错误的

本页勾选：横向逻辑 ✓（第 3 页承接第 2 页归因）；纵向逻辑 ✓（遮标题看图可反推"商超是主拖累"）；
一页一信息 ✓；Source ✓；sticker ✓；黑白打印 ✓（红绿柱配正负号，灰度下仍可辨）。

**数字一致性 [E-08] 的实战价值**：本页初稿的贡献柱曾写成 电商 +0.8、新品 +0.4、商超 −1.5、经销 −0.4——
贡献和 = −0.7，与起止差 −0.8 不符。QA 复核发现后重算为 电商 +0.4、商超 −1.1、经销 −0.1
（和 = −0.8 ✓），标题与 takeaway 数字同步修正。这正是 [E-08] 存在的意义：
**瀑布图贡献柱之和必须等于起止柱之差，交付前必须复核——不能跳过的检查。**
