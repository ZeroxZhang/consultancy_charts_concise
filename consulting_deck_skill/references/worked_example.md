可复算的最小示例（浮点比较设容差）：
```python
from math import isclose
rows = [(12.0, 7.2, 1.2, 3.6), (11.2, 6.4, 1.6, 3.2), (10.4, 5.3, 2.0, 3.1)]
assert all(isclose(total, sum(parts), abs_tol=1e-9) for total, *parts in rows)
delta = [new - old for old, new in zip(rows[1], rows[2])]
assert isclose(delta[0], sum(delta[1:]), abs_tol=1e-9)
print({'总降幅': delta[0], '商超': delta[1], '电商': delta[2], '经销': delta[3],
       '两年收入变化率': rows[2][0] / rows[0][0] - 1})
```

- **F-01｜descriptive｜Q-01/T-01**：2024–25年净收入下降0.8亿元，商超−1.1、电商+0.4、经销−0.1。证据E05…12、E-D02…07；公式结果见上表。分项闭合，描述在该合成范围内可靠，不能推出商超下降的原因。
- **F-02｜diagnostic｜Q-02/T-02｜unresolved**：现有辅助指标不足以区分产品、覆盖和客户迁移解释。证据E13…21及来源缺口；售价指数稳定不能排除产品吸引力下降，不能宣称“排除产品因素”。下一步按产品/门店/客户补数据；新证据可能改变干预方向。
- **F-03｜recommendation｜Q-03/04，依据T-01/02及T-03/04缺口**：建议先验证渠道需求与单位经济性，再讨论全量扩张。40%和18个月仍为待检验目标；该建议是可减少关键未知的分析判断，并非已证明的投资回报。规模、预算与时限不能从现有材料确定。

没有生成“2027年恢复增长”的预测，也没有给T-03/04写completed。这是分析边界清楚的阶段性答案。
