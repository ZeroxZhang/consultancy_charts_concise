# 经典框架与方法的开放检索

在基础方法路由不足、或材料显示有更多分析空间时读取。下面是可组合的检索入口，不是必做作业，也不是新增可量化结论的许可证。模型可用目录之外的方法，无需先扩充本文件。

## 从业务问题发现更多方法

| 问题／材料信号 | 可调用的经典方法与关键词 | 要形成的分析，而非填表 |
|---|---|---|
| 宏观环境改变进入条件 | PESTEL、情景规划、CAGE、情景交叉影响 | 外部变化→传导机制→暴露程度→选项/监测信号；国家差异要有具体证据 |
| 利润被谁获得、竞争怎样变化 | 五力、价值链、利润池、战略群组、成本曲线 | 交易/议价/替代机制与利润资本分布，不用“竞争激烈”代替分析 |
| 哪些优势真能维持 | VRIO／资源基础观、核心能力、活动系统、7S | 把稀缺性、可模仿性与组织承接连到实际证据；缺锚点不编成熟度分 |
| 从环境诊断形成可行行动 | SWOT→TOWS、3C、增长选择 | 将内外部证据配对成行动假设，比较可行性；四格本身不是结论 |
| 商业模式／价值主张重构 | Business Model Canvas、Value Proposition Canvas、JTBD、商业生态 | 客户任务、价值交换、成本收入与伙伴依赖闭合；区分已知与待试验 |
| 差异化与增长路径 | Ansoff、三层面增长、战略画布、四步行动ERRC、产品组合 | 哪些因素应减少/增加/去除/创造，客户与成本证据如何支持；不虚构价值曲线分值 |
| 客户分层与增长质量 | STP、客户旅程、漏斗、cohort、RFM、留存与LTV/CAC | 分群差异、转化/留存与贡献连起来；样本和窗口一致，避免把终身收入当净价值 |
| 多业务／项目选择 | BCG、GE九宫格、实物期权思路、决策树、情景/敏感性 | 同口径位置、经济性、资本与不可逆性共同影响选择；没有概率可保留条件分支 |
| 盈利与资本回报 | 利润驱动树、量价组合、单位经济性、盈亏平衡、DuPont、ROIC | 可复算恒等式与经营机制分开；资本/现金口径写明，避免平均数掩盖结构 |
| 运营等待、返工和约束 | SIPOC、价值流图、服务蓝图、约束理论、Little定律、鱼骨、5 Whys | 沿实际案例查等待/处理/瓶颈和替代解释；稳定流量前提不成立时不用Little定律推断 |
| 组织执行与决策权 | 7S、RACI、RAPID、利益相关者地图 | 责任、决定权、依赖和组织激励对应；RACI与RAPID的角色定义不能混用 |
| 战略到实施与学习 | 战略地图、平衡计分卡、KPI树、OKR、阶段门禁 | 指标与战略机制、基线、责任及反馈对应；目标不是已验证预测，相关指标避免重复计收益 |
| 不确定性与反证 | 假设树、预演失败、反事实、竞争假设、实验/准实验 | 找到最可能改选的证据，决定补什么；并非所有观察都能推断因果 |

基础BM/IN/ST/FM/DA/NT卡仍可作为执行起点。经典术语不能替代业务机制，适用前提在具体任务中核验。复杂财务/统计分析保存计算底稿，明确模型、估计和事实的差别。

## 使用与表达

选定方法时简记：它回答什么、输入/前提是否足够、做了什么、得出什么及边界。多个方法服务同一问题可以合并底稿，不必每个框架单做一页。没有重要新发现时，不为展示知识广度加入额外框架。

方法的输出可以转成数据图、比较表、机制图、战略屋、价值链、旅程或关系网络。先做分析，再决定是否保留原框架外形；“使用五力”不强制画五边形，“使用SWOT”不强制四格，“使用7S”不强制七个圆。

## 把丰富材料接成分析链

下列组合是本项目的实作提示；按问题选用，不要求逐项开展。它们可以帮助避免“知道框架名字，却仍只汇总材料”。

| 场景 | 从输入到结果的执行路径 | 可形成的主展品 |
|---|---|---|
| 增长快但价值下降 | 将客户/产品/地区明细连接到收入、成本、留存；用同口径贡献桥分离数量、价格、结构和成本；再比较分群分布与经营动作。声明交互归属，保留公司固定费用边界。 | 单位经济性桥＋分群差异图；高增长低贡献群体的局部放大 |
| 行业有规模但企业未获利 | 按价值链环节连接销售额、利润、投入资本与交易依赖；统一口径后看利润池和回报；用议价/替代/活动体系检验机制。缺资本时不把利润率当资本回报。 | 利润池/成本曲线＋价值链机制；缺数据则用证据明确的关系图 |
| 客户抱怨很多但动作不清 | 用交易/服务节点连接时间、触点、等待/处理和流失；访谈解释具体机制并保留反例；将可识别客群与贡献变化连接。没有代表抽样或因果设计，不把投诉频次当总体影响。 | 服务蓝图＋等待分布／旅程流失；改善假设与验证设计 |
| 新业务需要验证 | 将客户任务、价值主张、交付活动、伙伴与收入成本逐项连接；识别最敏感且最不确定的假设；明确最小验证、通过/停止条件及下一阶段承诺。 | 价值交换图＋假设敏感性＋验证路线图 |
| 多项目争夺资源 | 统一基线和期限，计算增量价值及现金需求；枚举预算/人力/依赖可行组合；保留相互作用、现状选项和端点/改选阈值。无概率不算伪期望值。 | 可行组合比较＋情景区间／tornado＋条件决策树 |
| 战略已定但执行反复卡住 | 从具体受阻决定追溯输入、决定权、执行责任、依赖与激励；比较正式职责和实际流程；设定少量能够触发行动的信号，避免为每个角色另建一套指标。 | 决策权矩阵＋泳道/依赖图＋学习反馈回路 |

业务框架帮助提出和组织问题；数据方法用于执行检验；视觉结构用于让读者看出答案。三者不要求一一对应，也不需要每个框架各占一页。

## 原始定义参考与边界

- [Harvard ISC：战略与活动体系](https://www.isc.hbs.edu/strategy/creating-a-successful-strategy/Pages/default.aspx)：用于竞争定位与活动一致性；结合基础IN/ST卡。
- [Strategyzer：商业模式画布](https://www.strategyzer.com/library/the-business-model-canvas)、[价值主张设计](https://www.strategyzer.com/value-proposition)：用于构造和检验商业/客户假设。这里提供使用路由，不复制其模板。
- [Blue Ocean：四步行动](https://www.blueoceanstrategy.com/tools/four-actions-framework/)：将既有竞争因素转成去除、减少、增加与创造的讨论；本项目另要求实际客户和经济性证据。
- [Bain：决策角色](https://www.bain.com/insights/who-has-d-how-clear-decision-roles-enhance-organizational-performance/)：需要RAPID时读取原定义，不从缩写猜角色。
- 其他术语是研究入口；需要采用其特定公式、量表或当前行业适配时再查原始定义。收录不代表每个框架已经有通用软件或完整案例验证。
