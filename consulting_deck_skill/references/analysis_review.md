# 分析验收 · v6

适用S2结束、S3综合及S7内容复核。它检验研究和建议是否成立；视觉/工程检查仍在 [workflow_qa.md](workflow_qa.md)。

## 检查编号

| 编号 | 实质检查 | 应查看的证据 |
|---|---|---|
| AQ-01 目标与范围 | 关键问题确实服务受众；研究型报告不被硬改成投资建议；editorial不被扩成咨询项目 | brief、议题树及不分析的理由 |
| AQ-02 问题覆盖 | 关键议题有回答或显式未知；影响结论的缺口不能被“模型做完”掩盖 | Q→T→F映射 |
| AQ-03 方法适配 | 输入与假设满足方法前提；有采用理由；评分阈值/权重有依据 | 方法卡、analysis_plan、数据口径 |
| AQ-04 实际执行 | 结果可复算或可复核；不是只列未来工作；财务恒等式与合计闭合 | 输入、工作表/脚本/公式或编码台账 |
| AQ-05 推断强度 | 描述、机制假设、因果证据、预测和建议区分；相关、份额与案例没有被过度解释 | findings的reasoning、替代解释 |
| AQ-06 反证与矛盾 | 主结论处理重要相反证据；同一发现不会在别页变成相反意思 | 原文、content_map、标题连读 |
| AQ-07 决策可行性 | 推荐对比现状/其他可行选项；收益、成本、现金、资源与依赖明确 | 增量模型、方案表、能力与约束；无推荐时注明不适用 |
| AQ-08 不确定性 | 目标与预测分开；区间、情景、敏感性有假设；未验证目标不冒充承诺 | 假设表、预测结果、改变建议的条件 |
| AQ-09 内容追踪 | 重要材料有去向与理由；关键反证影响正文；没有跨页重复计入收益 | source_inventory、evidence、content_map |
| AQ-10 分析到页面 | 按当前阶段核对追溯与传播：S2发现→任务/证据，S3标题→发现，S4页计划→标题，S7最终页→已审查结论 | 仅检查当前阶段已应产生的产物，见下文 |

**AQ-10分阶段执行**：S2只要求findings回溯任务/证据并有材料去向，不能要求尚未生成的ghost_deck、page_plan或最终页面。S3核对标题，S4补页计划，S7复核成稿。后续检查记“待相应阶段执行”，不预填pass，也不阻断已经完成本阶段检查的放行。

## 输出与放行

editorial只记录实际做过的关键核对、修正、限制与是否可继续，不生成十行AQ表或所有发现字段；不适用项无需逐项展开。复杂分析按下述完整格式。轻量不豁免数字、状态和关键推理的正确性。

`analysis_review.md`记录：模式、检查范围、逐项AQ结果与依据、缺陷清单、允许表达的结论、未决项及下一步。
逐项使用`pass / fail / not_applicable / not_reviewed`，不适用写理由，未执行如实记录。

- **ready**：适用项已核查通过；可以进入S3。
- **ready_with_limits**：适用项已核查，未知已转化为有限判断或验证计划；不存在仍会误导的断言。限制必须进入相关正文。
- **rework**：仍有错误口径、无推导数字目标、因果越界、隐去反证、关键结果不可复算等实质问题；修正或收窄后复核。

Blocking：错误可能改变核心结论或资源决策。Major：关键解释、方法前提或追溯缺失。Minor：不影响判断的表达问题。
Blocking/Major未解决不能放行；缺少资料不自动禁止交付，关键是停止依赖该缺口作确定判断。
分析未审查不能写ready；独立性与结论另记，作者自检也必须有证据。可合并小任务产物，但不省略实质检查。

## 独立复核与后续反馈

复杂分析或重大建议在S2安排未参与分析的代理复核，使用 [子代理模板](../assets/subagent_prompts.md) 的分析审查模板。提供原始材料、方法卡、实际计算、发现与计划，不提供作者自评分或希望得到的结论。
无代理工具时标“作者自检，独立分析审查未执行”。
S7重新核对最终标题与分析结果是否一致；设计阶段不得以节省空间为由删掉改变结论的限制。发现问题退回受影响T/F，不要求重做所有研究。

## 技能升级的行为验证

修改上游流程后，用独立代理完成真实形态的输入任务，仅给skill、用户请求和原材料。允许只运行到S3以隔离分析能力，不必每次渲染整套deck。
建议覆盖三类：混杂行业材料与相反案例；缺财务字段的投资目标；已确认文稿的轻量转换。保留原始请求、输出、计算及审查记录，不向执行者提示预期答案。
评估实际结果是否完成问题覆盖、拒绝不适用模型、处理反证、给出可复算发现并合理安排内容；不以出现指定标题、模型名称、文件数量或正则命中充当行为通过。
这类测试不证明任意行业、任意模型都可靠。不同执行模型的稳定性只能在实际跨模型测试后声称。
