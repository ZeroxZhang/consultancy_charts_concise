# 开放创作与适度检查 · V11.2

用户目标是让模型在丰富原始材料上发挥分析与设计能力。skill提供判断支点与可复用工具。创作自由要求主动综合、设计和取舍；成品质量同时包括内容、视觉表达和可用性，不能把“没有客观错误”作为全部目标。具体用户偏好以当前任务和项目约定为准，不从一次失败推导所有报告都必须使用同一风格。

## 底线、建议和实现边界分开

| 类别 | 如何处理 |
|---|---|
| 数据、推理和表达真实性 | 数字可复核；比较口径成立；定量编码正确；重要反证/未知不被隐藏；需要成立，不能以布局自由豁免 |
| 成品可用性 | 核心文字与展品可读、进入PDF；离线契约和同版哈希成立；失败要修复 |
| 用户明确视觉要求 | 禁止装饰侧边条及顶部色条卡片；逐页视觉均衡、有效内容对齐、来源空间与合理留白必须兑现，不能当可选美化 |
| 设计默认值 | 标题通常两行、数据通常15–16px、边距/模块数/布局比例是建议；在实际媒介中效果更好可以调整 |
| 工作过程 | 阶段可合并、少量文件可覆盖全流程；方法/图型ID及候选表用于复杂任务追溯，不要求每页全填 |
| 库内部阈值 | 配方的行数、字号或节点上限只表示这条实现路径的容量；可以换原生option、专用SVG或其他工具，不能据此降低原始分析深度 |

“检验不适用”和“未检验”不同；检查范围要真实，精简不等于把未知写成PASS。按任务合同的复杂性/重大结论风险决定独立审查，完整报告与片段不代替风险判断。局部编辑核对受影响内容；无变更页先核对页面身份与证据关联后继承原检查，有传播影响则扩大复查。不得把旧截图换上新哈希冒认本次看图，继承格式见[交付契约](delivery_system.md)。

## 充分利用原始材料

先建问题与数据地图，按对判断的影响深入：明细用于看分布、分群和异常，文本用于解释机制与反证，流程材料用于责任和依赖，财务资料用于经济性与资源约束。不要把所有文件先各压成五条摘要，再用摘要替代分析。

保存足以支持复查的定位与计算。可以使用SQL/Python/工作表，自定义方法、联合多个经典框架。抽样、聚合、Top N或合并尾项是正常编辑选择，但写清选择范围/分母，保留重要异常和原始明细去向；“保留所有材料”不等于全部塞入正文。

## 更自由的表达

图型库提供起点。原生ECharts、custom series、HTML表格、SVG图示、D3/Vega-Lite/ELK均可按需要使用。既有配方不适合时直接换实现，不要求先失败一次；更复杂路线说明关键编码和如何检查即可。

概念图的坐标由布局决定；定量图的位置/长度/面积由数据决定。可以画推测机制，但标明假设及验证条件；无需因为尚未证实因果而禁止所有机制图。图标和矢量插图可帮助识别、解释实物或流程，但不承载虚构证据。

作者可调整页面结构、字数、留白、颜色强调与展示精度。继承用户认可的字体和角色层级，主动用图形组织信息；成品同时满足读者任务与本次明确的视觉要求。自由构图并不豁免页面重心、关系展开和完整性，检查方法见[整页创作](slide_anatomy.md)。

## 检查按变更选择

| 任务 | 建议执行 | 不要求重复执行 |
|---|---|---|
| 新deck／大量内容改写 | 核对关键事实与计算、标题/证据一致，qa_deck＋实际看逐页与PDF | 整套组件/字体/引擎单元回归 |
| 少量文字或数据更新 | 受影响来源/计算/标题/图；重打包字体、重建PDF并检查受影响页 | 无关分析与无关组件测试 |
| 自定义图表/图示 | 验证该图的映射、标签、边/流量/尺度，最终截图与PDF | 所有56种图型逐一测试 |
| 引擎功能或默认示例改动 | test_engine，受影响样稿QA；导航/打印/离线 | 未改方法的完整研究验证 |
| 图表运行层改动 | 相应组件/配方/密集输入测试及代表成稿 | 不相关交付UI测试，除非影响打印/下载 |
| 字体打包/测量改动 | typography/font_metrics/browser/svg_scaling及代表样稿 | 不相关分析行为测试 |
| 交付/QA改动 | delivery及QA逃逸测试，正常稿能通过 | 全部方法卡重新研究 |
| 分析或编排规则大改 | 独立前向案例，覆盖新行为与合理轻量路径 | 机械执行固定18份报告；需要扩大验证时再扩 |

qa_deck将标题超过建议行数、接近字号基线等输出为warnings，交由实际视觉判断；明显越界、极小可见文字、打印丢展品、文件不同版输出errors。不要为了消除warning而牺牲正确表达；在简短review中解释影响即可。

每页0–4评分是可选诊断工具。正式完成看有没有影响事实、理解和决定的问题，不以每格评分或清单行数替代审查。无需额外用户签字；独立代理按复杂性使用并如实记录。
