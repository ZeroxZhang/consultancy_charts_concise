## 2. 决策树（四层判断）

1. **消息类型**：11 类中是哪一类？（确定后进对应行，通常不需要往下走）
2. **变量数与维度**：
   - 1 变量 1 系列 → 柱/条/线/饼；1 变量多系列 → 多线/堆积/100% 堆积；
   - 2 变量 → 散点/组合图；3 变量 → 气泡/颜色编码；>3 维度 → 小倍数分面或压缩成评估矩阵。
3. **数据点数量**：
   - 类别 ≤8 → 柱/饼；>8 → 水平条形/热力；
   - 时点 ≤6–7 → 柱（强调量级）；>6–7 → 折线（强调趋势）（Zelazny 规则）；
   - 观测点 ≤15 → 散点+直接标签；大样本 → 直方图/热力。
4. **读者与媒介**：
   - Reading deck → 高密度形态可用（多图页、表格页、热力表）；
   - 现场 presentation → 大图、低密度、单一强调色；
   - 两用 → 完整版 + 降密度现场版双出。

**最终输出**：推荐主图 + 1 个备选（备选用于受众不熟主图型时的降级，如 Mekko → 100% 堆积）。

## 3. 三个结论要点

1. **信息先于图表**：先写 action title 再从矩阵选图；信息一变图型必变。
2. **按证明责任选型**：比较、分布、结构、机制和计划分别选型；不设柱/条/线占比。可执行路由见 `exhibit_system.md`。
3. **一张图有明确任务**：同页多个互补证据允许组合；不要用没有统一语义的多功能图省页数——
   省下的页数会在解读混乱里加倍还回来。

## v4选型后的精加工

图型选定后读取 `analysis_exhibits.md`，明确总量/份额、差异公式、标签位置和回退方式。
复杂图不自动优于简单图；如果读者主要查精确值、多单位或不同口径，优先比较表。
Mekko仅在“总量大小与内部构成”同时重要时优先；同一数据只比较份额时用100%堆积或点图。
