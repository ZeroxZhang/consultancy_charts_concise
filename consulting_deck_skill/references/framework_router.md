先读 [分析规划](analysis_planning.md)。本索引回答“用什么方法研究”，[chart_matching.md](chart_matching.md)回答“如何表达已经得到的结果”。方法卡不是全套模型软件，也不是咨询公司内部方法的完整复刻。

## 业务问题入口

| 业务问题 | 首选方法链（按证据取舍） | 重点回避 |
|---|---|---|
| 公司怎样创造价值和赚钱 | BM-01商业模式 → BM-02客户任务 → FM-02单位经济性 | 用画布填满代替验证商业可行性 |
| 行业是否值得进入、哪个细分优先 | IN-01边界/规模 → IN-02五力 → IN-03价值链/利润池 → ST-03进入选项 → FM-05投资情景 | 把TAM或行业高增长等同于可获得利润 |
| 收入/利润为何变化 | DA-01口径与EDA → FM-01驱动树 → DA-02量价组合 → BM-02/DA-05检验解释 | 把贡献分解当因果；把GMV当净收入 |
| 增长来自哪里、是否可持续 | ST-01增长方向 → BM-02细分需求 → DA-03漏斗/cohort → FM-02经济性 | 只看总量均值；把新增与迁移重复计算 |
| 多业务如何配置资源 | ST-02组合 → FM-04资本回报 → FM-05现金/情景 | 由象限自动下投资或退出命令 |
| 项目值得投多少、何时回收 | FM-02 → FM-03预测 → FM-05增量现金流 → FM-06敏感性 | 先画增长曲线再编假设；强行计算IRR |
| 企业价值或交易价格是否有依据 | FM-03 → FM-07估值 → FM-06边界 | 混用企业/股权价值、现金流/折现率 |
| 经营效率怎样改善 | ST-04流程瓶颈 → FM-01成本机制 → FM-05增量收益 | 用裁员比例代替工作量与产能分析 |
| 组织怎样支持战略 | ST-05组织一致性 → ST-04责任/依赖 → FM-03资源预算 | 只重画组织架构；阶段箭头混合不同维度 |
| 大量文本或案例说明什么 | DA-01 → DA-06文本编码 → BM-02或CUSTOM对照分析 | 把采访频次当市场比例；把成功案例当必要条件 |
| 开放行业研究 | IN-01研究地图 → IN-02/03/04按议题取舍 → DA-01/06 → NT-05综合未知 | 没有材料就先宣布投资方向 |
| 已确认文稿变成deck | editorial核对 → NT-*叙事 → 既有图表路由 | 强行重做全套研究与财务模型 |

## 方法卡的按需使用

各卡使用五组字段，包含以下十项信息：
1. **问题/适用与禁用**：帮助什么决定，哪些问题不能回答。
2. **最低输入/假设**：字段、口径、粒度、证据及方法成立的条件。
3. **步骤/输出**：实际分析、公式或编码；产出结果结构。
4. **核验/回退**：计算、反证、稳健性与失效条件；数据不足时的可交付物。
5. **组合/来源**：可接续的方法、公开定义来源及本项目适配边界。

采用时在分析笔记中保留具体输入、结果与边界；不强制单独analysis_plan或每卡一张表，方法ID不能代替分析。
命名方法没有匹配项时可自定义，并记录相同契约；新增长期卡片应来自真实重复任务，而非追求目录数量。
不从主题品牌推断方法，不把模型数量或“经典”身份作为质量指标。
