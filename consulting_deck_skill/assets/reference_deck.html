原稿P04 → 基准比较 + 口径边界
材料沿用 · 待事实复核

海外收入占比提示扩张空间，跨市场基准仍需统一口径

先区分“企业经营的国际化程度”与“宏观出口规模”，再把增长目标拆到企业能力。

01｜海外收入占比：差距信号

2024年，%；各市场样本范围不同，不能作为精确追赶目标
A股15%低于所列海外市场样本；差距可提出研究问题，不能单独证明可实现增量。

02｜需要一起读的经营信号

12.15万亿元｜海外收入旧稿列2025年A股海外收入同比+12%；这是规模信号，与2024年占比不混算。
57.3%｜民企外贸占比主体结构说明参与广度；分母是外贸总值，不是上市公司营业收入。
从“空间”转为“能力”下一步核验行业构成、可进入市场、利润率与资本占用，形成企业层面的目标。
决策含义：先建立企业同口径基线，再讨论海外收入占比目标及投入回报。

原稿P17 → 定性评分矩阵
分析判断 · 原评分待核

主观吸引力评分应透明展示，不宜伪装为精确市场坐标

沿用旧稿的四维评分，取消不可比规模气泡；等级表达相对判断，不表示可测量的距离。

01｜分析判断矩阵

1–5分；规模/增速/壁垒高分不等于综合优先，政策风险高分表示风险较高
矩阵保留旧稿判断的可追溯性；未给权重与评分证据，因此不计算综合得分。

02｜评分使用边界

等级不是测量旧稿评分定义不完整，当前仅供讨论；严禁将等级映射为精确百分比位置。
风险维度方向相反政策风险5分表示风险更高；用文字说明，不用绿色把高分渲染成“更好”。
决策前补三项评分锚点与证据、业务特定权重、改变假设后的敏感性检验。

原稿P18 → 决策表
建议 · 条件待验证

市场、模式与进入条件必须成套比较，投入建议才能执行

把三列独立建议改为“业务组合—条件—证据缺口—下一动作”的决策表。

01｜条件化方案比较

业务组合区域 / 模式成立条件未决证据下一步动作
新能源车 / 储能东盟、中东、拉美
本地产能或合资		准入清晰、渠道具备、产能与需求匹配全成本、关税、利用率、伙伴能力进入市场尽调，核验投资门槛
AI内容 / IP品牌按细分市场选择
产品与生态合作		内容/数据合规、留存和获客经济性成立区域收入、付费、毛利与合规成本开展可回收的产品/渠道试点
跨境电商存量既有市场
海外仓、半托管		履约和库存效率可改善贡献利润退货、仓租、库存周转与平台费先优化单元经济性再扩规模
低价直邮 / 重资产扩店逐市场评估
不统一默认退出		现金流可承受且有可验证差异化政策情景与盈亏平衡限额试验，设止损条件
收益门槛｜财务牵头将价格、履约、税费、获客和资本占用纳入同一模型；由企业批准回报门槛。
进入门槛｜业务与法务列明市场准入、伙伴能力和资源依赖；无法满足时调整区域或进入模式。
退出门槛｜运营牵头试点前确定复盘时点、损失上限与停止条件，避免因沉没成本持续加码。
本轮决策请求：批准尽调与试点范围；大规模投入须在收益、风险和退出条件明确后另行审议。

原稿P19 → 泳道 + 阶段门禁
建议 · 时间窗口非承诺

实施计划需绑定责任、交付与退出条件，而不仅是三个阶段

以下18个月为原稿建议时间窗；用泳道表达工作衔接，用门禁约束投入。

01｜责任泳道与阶段依赖

门禁A｜允许启动准入路径、责任人、预算上限及退出条件齐备；条件未满足不进入试点。
门禁B｜允许扩张试点实际毛利、现金周转与客户指标达到企业批准阈值。
门禁C｜复制或退出达到复制标准才放大；未达标则调整假设、缩减投入或退出。
